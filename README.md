# HiTo-norms

Документы нормативной базы для окна «Справочник норм» плагина [HiTo](https://github.com/Hishwaia/HiTo-update).
Плагин скачивает нужный документ по требованию и открывает его на странице таблицы или пункта;
каждый файл проверяется по контрольной сумме, вшитой в плагин.

Тексты норм опубликованы органами, которые их утвердили, и выложены без изменений. Если вы
правообладатель и возражаете против размещения документа, напишите на hitoplugin@gmail.com —
файл будет убран.

---

Normative documents for the “Norms reference” window of the [HiTo](https://github.com/Hishwaia/HiTo-update)
plugin. The plugin downloads a document on demand and opens it on the page of the table or clause;
every file is verified against a checksum built into the plugin.

The texts are published by the bodies that approved them and are provided unchanged. If you hold
rights to a document and object to it being here, write to hitoplugin@gmail.com and the file will
be removed.
